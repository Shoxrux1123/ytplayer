# YT Фон — YouTube для музыки в фоне (Android)

Тёмная тема · вход в Google-аккаунт (твои рекомендации, подписки, история) ·
фон без остановок · управление из шторки, с экрана блокировки и кнопками наушников ·
только 4 вкладки: **Главная, Shorts, Подписки, История**.

## Как получить APK (без Android Studio, через GitHub, бесплатно)

1. Зарегистрируйся на github.com → **New repository** (можно Private) → создай.
2. На странице репозитория: **Add file → Upload files** → перетащи **всё содержимое** папки `YTPlayer`
   (включая скрытую папку `.github`; если браузер её не берёт, создай файл вручную:
   **Add file → Create new file**, имя `.github/workflows/build.yml`, вставь содержимое из архива).
3. Открой вкладку **Actions**, там запустится «Build APK» (≈4–6 минут).
4. Когда появится зелёная галочка, открой сборку и скачай **YTPlayer-apk** внизу страницы (zip с `app-debug.apk`).
5. Перекинь APK на телефон → открой → разреши «Установка из неизвестных источников».

Можно и через Android Studio: **Open** → папка `YTPlayer` → **Build → Build APK(s)**.

## Первая настройка на Galaxy A53

1. При запуске разреши **уведомления** (без них не будет плеера в шторке).
2. На вопрос про батарею нажми **Разрешить**.
3. Обязательно для Samsung: **Настройки → Приложения → YT Фон → Батарея → «Без ограничений»**.
4. Дополнительно: **Обслуживание устройства → Батарея → Ограничения фонового использования →
   «Приложения, которые никогда не переходят в спящий режим» → добавь YT Фон**.
5. Войди в аккаунт: нажми на иконку профиля вверху справа → **Войти**.

## Как это устроено

| Файл | Что делает |
|---|---|
| `MainActivity.kt` | Экран, нижние вкладки, кнопка «Назад» сворачивает, а не закрывает |
| `WebHolder.kt` | Один WebView на всё приложение (музыка не обрывается при повороте), тёмная тема, вход Google |
| `assets/inject.js` | Страница всегда «видна» для YouTube, автоклик «Продолжить просмотр?», автопереход к следующему видео, команды плеера |
| `PlaybackService.kt` | Фоновая служба + MediaSession: шторка, экран блокировки, наушники, обложка, перемотка |
| `MediaHub.kt` | Связь между страницей и уведомлением |

- **Следующий трек**: плейлист → кнопка «Далее» → первое видео из «Похожих». В Shorts — следующий шортс.
- **Предыдущий**: если прошло больше 5 секунд, трек начинается сначала, иначе открывается предыдущее видео.
- Смахнул приложение из «Недавних» — музыка продолжает играть. Полностью остановить её можно **крестиком** в уведомлении.
- Ссылки YouTube из Telegram и других приложений можно открывать прямо в YT Фон.

## Если что-то не работает

- **Google пишет «Браузер или приложение небезопасны»**: попробуй войти ещё раз через пару минут.
  Помогает и такой способ: сначала войти в аккаунт на m.youtube.com в Chrome на этом же телефоне, потом повторить вход в приложении.
- **В фоне всё равно останавливается**: проверь пункты 3–4 настройки. Режим энергосбережения Samsung тоже может мешать.
- **YouTube поменял вёрстку и кнопка «Следующий» перестала работать**: селекторы находятся в функциях
  `clickNextBtn` и `openFirstRelated` в `inject.js`.

> Воспроизведение в фоне без YouTube Premium нарушает условия YouTube. Приложение предназначено для личного использования.
